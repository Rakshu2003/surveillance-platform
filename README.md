# SentinelAI - AI Surveillance Platform

Ve-Lyra Internship Assignment | May 2026

## Features
- YOLOv8 Person Detection
- AI Threat Scoring
- GenAI Incident Summaries (Groq LLaMA)
- Live React Dashboard
- DOCX Report Download

## Tech Stack
- Backend: FastAPI + Python
- Vision: YOLOv8
- GenAI: Groq + LLaMA 3.3
- Frontend: React + TypeScript
- Database: PostgreSQL + MongoDB + Redis

## Setup
1. pip install -r requirements.txt
2. Add GROQ_API_KEY to .env
3. Start Docker databases
4. uvicorn backend.app.main:app reload
5. cd frontend and npm start
6. Open http://localhost:3001
